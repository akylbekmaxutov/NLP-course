Opening

What is Natural Language Processing?

Natural Language Processing (NLP) is the field of Artificial Intelligence that studies how computers can process, understand, analyze, and generate human language.

Human language is not a table of numbers. It is text and speech produced by people: messages, questions, news, documents, reviews, voice commands. NLP is the set of methods that turns this material into something a computer can work with — and then turns the result back into language a person can read.

The basic flow

  • Human Language →
  • Natural Language Processing →
  • Understanding / Classification / Search / Generation
Understanding

What does this text mean?

Intent Detection, Named Entity Recognition, Sentiment Analysis.

Classification

Which category does it belong to?

Topic labels, spam filters, complaint routing.

Search

Where is the answer?

Semantic Search, Retrieval, Ranking, Question Answering.

Generation

How do we answer?

Machine Translation, Summarization, dialogue, Large Language Models.

Concept

Why is NLP difficult?

A programming language has one grammar and no exceptions. Human language has neither. It is:

Ambiguous

The same word can mean different things.

Contextual

Meaning depends on the sentences around it.

Multilingual

One message can mix several languages.

Constantly changing

New words, slang, and abbreviations appear all the time.

Culture-dependent

Politeness, irony, and references are local.

Morphologically rich

In Kazakh, one root produces a very large number of surface forms.

Ambiguity

Kazakh example

Ол банкте отыр.

Without context, at least two readings are possible:

  • the person works at a bank
  • the person is physically sitting inside a bank

A human resolves this from the situation. A model has to learn it from context.

Morphology

Kazakh is an agglutinative language: suffixes are added one after another. The same root appears in many surface forms.

One root, many forms
кітап
book
кітаптар
books
кітаптарым
my books
кітаптарымыздан
from our books

For a computer these are four completely different strings. Making them comparable is exactly the job of Tokenization and Lemmatization, which we meet later in the course.

Multilingual reality

A realistic message in Kazakhstan

Сәлем, meeting сағат 15:00-де болады, Teams-ке кіресің бе?

In one short sentence we already have:

  • Kazakh grammar and word order
  • English terminology (meeting, Teams)
  • numbers and time formats
  • punctuation and Kazakh suffixes attached to English words
This mixture is normal here — and it is exactly what makes Kazakhstan an interesting environment for NLP research and products.

Keyword matching alone is not enough: the query has to be understood, not just matched.

Use case 06

Translation

Machine Translation learns to map a sentence in one language to a sentence in another while keeping the meaning.

  • Kazakh ↔ Russian
  • Kazakh ↔ English
Example sentence

Қазақстанның астанасы — Астана.

Modern systems do not translate word by word. They encode the whole sentence and generate the translation from that representation — a mechanism we will meet again when we reach Transformers.

Big picture

The evolution of NLP

Each step did not delete the previous one — it added a new way of representing language. Our course roughly follows this path.

  • Rules→
  • Bag of Words→
  • Machine Learning→
  • word2vec→
  • RNN / LSTM→
  • Transformers→
  • BERT / GPT→
  • Large Language Models→
  • RAG / Agents
We keep this conceptual for now. The mathematics arrives later, when we have the vocabulary for it.

Question 1

In your own words: what is Natural Language Processing?

Show Answer

Question 2

Why is “Ол банкте отыр” difficult for a computer?

Show Answer

It is ambiguous: the person may work at a bank or be physically sitting inside one. Only the surrounding context decides, and the model has to learn that context.

Question 3

Name the four families of NLP tasks from this lecture.

Show Answer

Understanding, Classification, Search, and Generation.

Question 4

кітап · кітаптар · кітаптарым · кітаптарымыздан Why is this a problem for a program that compares strings?

Show Answer

Kazakh is agglutinative, so one root produces many surface forms. To a program these are four unrelated strings, even though they share a meaning. Tokenization and Lemmatization exist to make them comparable.

After the lecture

Self-check quiz

Ten questions to test yourself. Choose one answer per question — you get the result immediately.

  1. Natural Language Processing is a field of…

    NLP is the part of Artificial Intelligence concerned with human language.

  2. A system labels “Ұлттық банк” as ORGANIZATION. Which task is this?

    Named Entity Recognition finds names in text and assigns them a type: PERSON, LOCATION, ORGANIZATION, COUNTRY.

  3. Which property of language does “Ол банкте отыр” demonstrate?

    One sentence, two possible readings — that is ambiguity. Context resolves it.

  4. “Kazakh is an agglutinative language” means that…

    кітап → кітаптар → кітаптарым → кітаптарымыздан: each suffix adds meaning, which is why one root yields very many surface forms.

  5. “Сәлем, meeting сағат 15:00-де болады” is an example of…

    Kazakh grammar with English terminology inside it — completely normal in Kazakhstan, and a real difficulty for NLP systems.

  6. What is the correct pipeline for a voice assistant?

    ASR turns speech into text at the start; TTS turns the answer back into speech at the end. NLP works in between, on text.

  7. A system reads “Бүгін Астанада ауа райы керемет екен!” and outputs Sentiment: Positive. Which task family is that?

    Sentiment Analysis is an Understanding task: the system extracts meaning from the text rather than producing new text.

  8. Which of these is not an NLP task?

    Image compression works on pixels, not on language. The other three all take human language as input.

  9. In the evolution of NLP, which came first?

    Rules → Bag of Words → Machine Learning → word2vec → RNN / LSTM → Transformers → BERT / GPT → Large Language Models → RAG / Agents.

  10. How do modern Machine Translation systems work?

    Word-by-word replacement loses meaning. Modern systems represent the sentence as a whole — the mechanism behind Transformers.
