Motivation

Before models understand language, we first need to work with text.

Every NLP pipeline starts with plain, messy text: extra spaces, phone numbers, dates, hashtags, mixed languages. The oldest and still the most used tool for that first pass is:

Regular Expressions — Regex

Definition

What are Regular Expressions?

Regular Expressions are patterns used to find, extract, validate, split, or replace text.

  • Text +
  • Pattern =
  • Match

A Regex does not understand meaning. It only describes shape: “four digits in a row”, “a word starting with #”, “two digits, a dot, two digits, a dot, four digits”. That is already enough to solve a surprising amount of real work.

Examples

Regex with Kazakhstan data

Example 01 · Phone numbers

Kazakhstan phone numbers

Менің нөмірім +7 701 123 45 67.
Кеңсе: +7 7172 55 44 33.

Educational pattern:

\+7[\s\d]+

Matched fragments:

  • +7 701 123 45 67
  • +7 7172 55 44 33
Note the escaped \+: a bare + means “one or more”. Production-grade validation would need stricter rules — this pattern happily accepts nonsense like +7 999999999999.
Example 02 · Years

Extract years

Қазақстан тәуелсіздігін 1991 жылы алды.
EXPO 2017 Астанада өтті.

Pattern: \b\d{4}\b

Result:

  • 1991
  • 2017

The word boundary \b stops the pattern from taking four digits out of the middle of a longer number.

Example 03 · Dates

Extract dates

Кездесу 24.08.2026 күні Астанада өтеді.

Pattern: \b\d{2}\.\d{2}\.\d{4}\b

Result:

  • 24.08.2026

The dot is escaped as \. — an unescaped . would match any character.

Example 04 · Vehicle plates

Kazakhstan vehicle plates

123 ABC 01
777 KZK 02

Simplified educational pattern:

\d{3}\s[A-Z]{3}\s\d{2}

Real plate formats and their validation rules are more complex than this; the pattern is here to show fixed-length groups.

Example 05 · Hashtags

Find hashtags

Бүгін #Astana қаласында #AI туралы конференция өтті.

Pattern: #\w+

Result:

  • #Astana
  • #AI
In JavaScript \w means [A-Za-z0-9_] only, so #Астана would not match. Kazakh and Russian hashtags need a Unicode-aware pattern — a good reminder that even Regex is language-dependent.
Example 06 · Cleaning

Clean extra spaces

Алматы     Қазақстанның    ең ірі қалаларының бірі.

Pattern: \s+ — replacement: " "

Output:

Алматы Қазақстанның ең ірі қалаларының бірі.

Normalising whitespace is one of the very first steps of almost every text-processing pipeline.

Example 07 · Emails

Extract email addresses

Сұрақтарды info@example.kz адресіне жіберіңіз.

Simplified teaching pattern:

[\w.-]+@[\w.-]+\.\w+

This is not a complete, RFC-compliant email validator. It is good enough to find addresses in text, which is usually what an NLP pipeline actually needs.
Reference

Regex syntax cheat sheet

Regular Expression syntax with Kazakhstan-related examples
Syntax Meaning Example
. any character А.тана matches Астана
\d digit \d\d\d → 701
\w word character #\w+ → #Astana
\s whitespace \s+ → the gap in Алматы   қаласы
+ one or more \d+ → 2026
* zero or more ab* matches a too
? optional \+?7 matches 7 and +7
{n} exactly n times \d{4} → 1991
[abc] one of these characters [АӘ] matches А or Ә
[^abc] anything except these [^0-9] → any non-digit
^ start of string ^Астана
$ end of string \.$ → sentence-final dot
(...) group (\d{2})\.(\d{2}) → day and month
| OR Астана|Алматы
\b word boundary \b\d{4}\b → 2017

    Code example

    The same patterns in Python

    In the practical part of NLP work we use Python. The re module gives us the same Regex engine idea. 

    import re

text = "EXPO 2017 Астанада өтті."
years = re.findall(r"\b\d{4}\b", text)

print(years)

    Output:

    ['2017']
    import re

text = "Кездесу 24.08.2026 күні өтеді."

dates = re.findall(
    r"\b\d{2}\.\d{2}\.\d{4}\b",
    text
)

print(dates)

    Output:

    ['24.08.2026']
    The r"..." prefix marks a raw string, so the backslashes reach the Regex engine unchanged. Without it you would have to write "\\b\\d{4}\\b".
