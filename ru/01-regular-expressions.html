Мотивация

Прежде чем модели начнут понимать язык, нам нужно научиться работать с текстом.

Любой NLP pipeline начинается с обычного «грязного» текста: лишние пробелы, номера телефонов, даты, hashtag-и, смешанные языки. Самый старый и до сих пор самый используемый инструмент для этого первого шага:

Regular Expressions — Regex

Определение

Что такое Regular Expressions?

Regular Expressions — это шаблоны (patterns), которые используются, чтобы находить, извлекать, проверять, разделять или заменять текст.

  • Text +
  • Pattern =
  • Match

Regex не понимает смысла. Он описывает только форму: «четыре цифры подряд», «слово, начинающееся с #», «две цифры, точка, две цифры, точка, четыре цифры». Этого уже достаточно, чтобы решить удивительно большую часть реальных задач.

Примеры

Regex на казахстанских данных

Пример 01 · Номера телефонов

Казахстанские номера телефонов

Менің нөмірім +7 701 123 45 67.
Кеңсе: +7 7172 55 44 33.

Учебный шаблон:

\+7[\s\d]+

Найденные фрагменты:

  • +7 701 123 45 67
  • +7 7172 55 44 33
Обратите внимание на экранированный \+: обычный + означает «один или более». Промышленная валидация требует более строгих правил — этот шаблон спокойно примет бессмыслицу вроде +7 999999999999.
Пример 02 · Годы

Извлечь годы

Қазақстан тәуелсіздігін 1991 жылы алды.
EXPO 2017 Астанада өтті.

Шаблон: \b\d{4}\b

Результат:

  • 1991
  • 2017

Граница слова \b не даёт шаблону взять четыре цифры из середины более длинного числа.

Пример 03 · Даты

Извлечь даты

Кездесу 24.08.2026 күні Астанада өтеді.

Шаблон: \b\d{2}\.\d{2}\.\d{4}\b

Результат:

  • 24.08.2026

Точка экранирована как \. — неэкранированная . совпала бы с любым символом.

Пример 04 · Автомобильные номера

Казахстанские автомобильные номера

123 ABC 01
777 KZK 02

Упрощённый учебный шаблон:

\d{3}\s[A-Z]{3}\s\d{2}

Реальные форматы номеров и правила их проверки сложнее; шаблон здесь нужен, чтобы показать группы фиксированной длины.

Пример 05 · Hashtag

Найти hashtag-и

Бүгін #Astana қаласында #AI туралы конференция өтті.

Шаблон: #\w+

Результат:

  • #Astana
  • #AI
В JavaScript \w означает только [A-Za-z0-9_], поэтому #Астана не совпадёт. Для казахских и русских hashtag-ов нужен шаблон, учитывающий Unicode — хорошее напоминание о том, что даже Regex зависит от языка.
Пример 06 · Очистка

Убрать лишние пробелы

Алматы     Қазақстанның    ең ірі қалаларының бірі.

Шаблон: \s+ — замена: " "

Результат:

Алматы Қазақстанның ең ірі қалаларының бірі.

Нормализация пробелов — один из самых первых шагов почти любого pipeline обработки текста.

Пример 07 · Email

Извлечь email-адреса

Сұрақтарды info@example.kz адресіне жіберіңіз.

Упрощённый учебный шаблон:

[\w.-]+@[\w.-]+\.\w+

Это не полный, соответствующий RFC валидатор email. Но его достаточно, чтобы находить адреса в тексте — а обычно NLP pipeline нужно именно это.
Справочник

Синтаксис Regex — cheat sheet

Синтаксис Regular Expression с примерами из казахстанского контекста
Синтаксис Значение Пример
. любой символ А.тана → Астана
\d цифра \d\d\d → 701
\w символ слова #\w+ → #Astana
\s пробельный символ \s+ → промежуток в Алматы   қаласы
+ один или более \d+ → 2026
* ноль или более ab* совпадает и с a
? необязательно \+?7 → 7 и +7
{n} ровно n раз \d{4} → 1991
[abc] один из этих символов [АӘ] → А или Ә
[^abc] всё, кроме этих [^0-9] → любой нецифровой символ
^ начало строки ^Астана
$ конец строки \.$ → точка в конце предложения
(...) группа (\d{2})\.(\d{2}) → день и месяц
| ИЛИ (OR) Астана|Алматы
\b граница слова \b\d{4}\b → 2017

Результат

    Пример кода

    Те же шаблоны на Python

    В практической части работы с NLP мы используем Python. Модуль re даёт нам ту же идею Regex. 

    import re

text = "EXPO 2017 Астанада өтті."
years = re.findall(r"\b\d{4}\b", text)

print(years)

    Вывод:

    ['2017']
    import re

text = "Кездесу 24.08.2026 күні өтеді."

dates = re.findall(
    r"\b\d{2}\.\d{2}\.\d{4}\b",
    text
)

print(dates)

    Вывод:

    ['24.08.2026']
    Префикс r"..." обозначает raw string, поэтому обратные слеши доходят до Regex-движка без изменений. Без него пришлось бы писать "\\b\\d{4}\\b".

    Мини-задания по Regex

    Попробуйте каждое в playground выше, прежде чем открывать ответ.

    Задание 1 — Найти все годы

    Қазақстан 1991 жылы тәуелсіз болды. Астана EXPO 2017 көрмесін қабылдады.

    Показать ответ

    Совпадения: 1991 2017

    Задание 2 — Извлечь все hashtag-и

    Задание 3 — Найти дату

    Курс 24.08.2026 күні басталады.

    Показать ответ

    Задание 4 — Только номера телефонов
